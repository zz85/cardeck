CarPlay Sender · Phone UI Material Redesign

Material Design 3 · dark · signal-cyan primary — the phone on the right is interactive; switch connection-state previews on the left

STATE PREVIEW

REDESIGN RATIONALE

  • Hero card is the single focus: visualized connection status + main action, replacing the old row of scattered buttons
  • Connection prep as a checklist: hotspot / Bluetooth / audio permission, each with a status badge, so what's missing is obvious at a glance
  • Debug info collapsed: Shell global status and log are collapsed by default, out of the way in daily use
  • Zero features removed: all existing buttons / switches / inputs are kept, only the hierarchy is reorganized
  • M3 tokens: tonal variables map directly to Android themes.xml for 1:1 reproduction

ANDROID MAPPING

  • Card → MaterialCardView (24dp corners)
  • Switch → MaterialSwitch · main button → MaterialButton(pill)
  • Theme → Theme.Material3.Dark + custom tonal palette
  • Dialog → MaterialAlertDialogBuilder · toast → Snackbar
